# Ferramentas antigas arquivadas

Os 36 scripts antigos de montagem, atualização e diagnóstico foram retirados de `Assets` e guardados como `.cs.txt`. Eles não participam da compilação da Unity. Seus `.meta` e os metadados das pastas antigas permanecem aqui para rastreabilidade.

O painel `Memorias Tecidas > Organizar projeto` e o inspector de superfície continuam em `Assets/MemoriasTecidas/Codigo/Editor`, quando já existiam no projeto. Scripts de Editor que você havia excluído não são reinstalados.

Estes arquivos registram caminhos históricos. Não os copie individualmente para `Assets`: alguns regeneram conteúdo. Para desfazer a reorganização inteira, use o restaurador no backup descrito em `Docs/Migracao22.md`.
